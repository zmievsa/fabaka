Fabaka Source

⌘Tab switches apps. Fabaka switches windows.

Hold ⌘ and press Tab: every window is listed, most recent first. Release ⌘ to jump to the selected one. Every Space, every screen, minimized and hidden windows included.

$ brew install --cask zmievsa/tap/fabaka

Needs macOS 26 on Apple silicon.

What each switcher lets you reach

  1. Browser
  2. Editor
  3. Chat
  4. Design
  5. Notes
  6. Music
  7. Terminal
  8. Mail

While the list is open, W closes the selected window and Q quits its app.

Apps left running with no windows are listed too, so Q cleans them up. Apps meant to always run (Finder, a VPN, a terminal with a hotkey) are told to Stay and are left out.
