Fabaka. Fetch.

Fabaka is a fast ⌘Tab for Mac.

Hold ⌘ and press Tab: every window is listed, most recent first. Release ⌘ to jump to the selected one.

$brew install --cask zmievsa/tap/fabaka

Quiet.

A plain list of windows, and nothing else.

Drop it.

Apps left running with no windows are listed too, so Q cleans them up.

While the list is open, W closes the selected window and Q quits its app.
